## Goal

Make every current product-facing source describe a generic portable advisor
for individuals whose exact private details live in separately controlled
workspaces. Remove professional-only and named-initial-user positioning without
promoting unsupported specialist advice or effectiveness claims.

## Non-Goals

- Changing workspace tooling, context modes, or runtime capture behaviour owned
  by TASK-017 through TASK-019.
- Rewriting Git history or deleting historical workflow evidence.
- Claiming personal-context behaviour is validated before TASK-020.

## Users & Context

- Individuals evaluating or installing Strategic Advisor need to see a generic
  product rather than an owner-specific package.
- Maintainers need one coherent public contract that distinguishes exact
  private context from public source and specialist authority.

## Requirements (Outcome-Focused)

- R1. Constitution, README, INSTALL, ARCHITECTURE, PRODUCT-CONTRACT, and current
  product-facing host language define the target user generically.
- R2. Product-facing first-use routes contain no hard-coded initial-user or
  household positioning; historical evidence may remain explicitly historical.
- R3. Whole-person exact context is a core strategic input while diagnosis,

  evidence satisfies the relevant behavioural gate.
