## Goal

current-source evidence without claiming private dogfood or general
effectiveness.

personal-context authority and runner/reviewer needed, then perform one fresh
temporary workspace journey.

2. Run exact-runtime behavioural cases and hard-gate review.
3. Reproduce runtime/install artifacts and leakage checks.
4. Run the generic end-to-end workspace journey.
