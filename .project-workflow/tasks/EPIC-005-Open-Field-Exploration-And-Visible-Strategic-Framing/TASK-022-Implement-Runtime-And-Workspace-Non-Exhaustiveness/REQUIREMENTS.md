## Goal

Implement the canonical reasoning and workspace semantics that make current
projects informative but non-exhaustive, so broad objectives can be tested
against current, adjacent, and outside vehicles without inventing feasibility.

## Non-Goals

- Public discoverability content owned by TASK-023.
- Exact-runtime behavioural proof owned by TASK-024.
- A new durable opportunity file or automatic capture of speculative ideas.

## Users & Context

- Users whose current workspace contains projects that may not be viable
  vehicles for the higher objective being discussed.
- Users asking bounded project questions that should not be widened without a
  material reason.

## Requirements (Outcome-Focused)

- R1. Add search-boundary selection and non-exhaustive portfolio semantics to
  canonical runtime behaviour.
- R2. Treat `PORTFOLIO.md` as current commitments, candidates, roles, and
  opportunity costs rather than the permitted universe.
- R3. For broad outcomes, allow current, adjacent, and outside strategy
  families and state when no current project has a supported causal bridge.
- R4. Keep all new paths as hypotheses until qualifying evidence supports a
  candidate action.
- R5. Preserve bounded requests and strongest-current-path conclusions without
  novelty theatre.
- R6. Keep speculative options non-durable unless a separate write authority
  permits reviewed structured capture.
