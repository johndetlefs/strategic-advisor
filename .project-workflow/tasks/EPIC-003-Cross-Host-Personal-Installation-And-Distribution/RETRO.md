## Lessons

- Personal ChatGPT and managed ChatGPT Skills are different delivery surfaces. Paid-personal users need a Custom GPT adapter whose Instructions and Knowledge are mechanically derived from the canonical runtime.
- Cross-host delivery is easiest to reason about when one structured ledger records package readiness, installation, activation, behavioural smoke, sharing, validation, support, and adoption separately for each exact host.
- A local browser transfer restriction is an execution-surface problem, not evidence that the package is defective. An already-authenticated supported browser completed the same exact 19-file public upload without changing product scope.
- Enterprise account work should finish as a package/preflight/handoff result when only the member or organisation owner can perform the private upload. The account activation state stays unobserved instead of becoming a permanent engineering blocker or a false pass.
- Project Workflow Epic proof owners must be recorded as exact child IDs in `EPIC-CONTRACT.md`; descriptive role labels cannot satisfy the acceptance audit.
