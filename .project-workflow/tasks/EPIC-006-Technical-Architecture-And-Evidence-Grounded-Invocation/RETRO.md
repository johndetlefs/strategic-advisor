# Epic Retro

- Epic: EPIC-006
- Title: Technical Architecture And Evidence-Grounded Invocation
- Last updated: 2026-08-14

## Lessons

- Technical architecture belongs inside the canonical reality protocol only when a material boundary, ownership, migration or future-change decision is live. Technical vocabulary and repository context are insufficient activation evidence.
- Baseline identity must be guarded in the domain-independent evidence core. A strong lens applied to a stale demonstration, wrong revision or incomparable scope still produces a bad decision.
- Implicit invocation cannot be inferred from answer quality. Retained host traces must show which installed runtime files were or were not read for the exact session.
- Mutable generated inventories can stale historical structured-evidence hashes. Historical claims should either point to immutable retained evidence or explicitly describe compatible successor inventories when the canonical generated artifact evolves.
- Clean deterministic packaging requires a committed source revision; smoke authority and result commits therefore remain intentionally separate.
