## Claim Promotion Rules

- Documented semantics may support `implemented` only after canonical source
  changes and static validation; it does not establish model behaviour.
- Exact-runtime synthetic evidence is bounded to the exact source/package,
  model, host, activation and frozen case authority.
- Private Strategy Workspace dogfood is a separate repository and proof layer.
  It cannot be copied here or used as a public effectiveness claim.
- Package preparation, protected-main integration, publication, fresh download
  verification, host activation, support, adoption and effectiveness remain
  distinct delivery states.
